# Real VRI cluster demo fixture

A 12-polygon cluster selected from the public TSA 24 block geometry in
`femic-tsa24-instance/runtime/geometry/tsa24-blocks.geojson`. Polygon coordinates are
translated to a local origin. Trees are synthetic: Nemora places stems by a Poisson
process at 120 stems/ha, with a deterministic lognormal DBH draw and placeholder
height, crown, and biomass allometry. The cluster is a demo, not an inventory claim.

Generated: 12 polygons, 12588 trees.
