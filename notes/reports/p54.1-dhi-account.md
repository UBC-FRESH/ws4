# P54.1 DHI biodiversity account

Date: 2026-10-26
Issue: ws4 #376 (parent #375)
Branch: `feature/p54.1-dhi-account`

## Product

- SILVIS Lab MODIS 6.1 Terra NDVI Composite RGB, 2003-2022, 500 m.
- Three bands: cumulative DHI (`cum`), minimum DHI (`min`), variation DHI
  (`var`), stored as 8-bit values and divided by 255.
- Licence: public, no restrictions. Source page:
  <https://silvis.forest.wisc.edu/data/dhis/>.
- The pilot subset was requested from the SILVIS WCS:

```text
https://geoserver.silvis.forest.wisc.edu/geoserver/wcs?service=WCS&version=2.0.1&request=GetCoverage&CoverageId=dhis_mod6__MODIS_6.1_Terra_NDVI_Composite+RGB&format=image%2Ftiff&subset=Long(-123.0,-122.6)&subset=Lat(49.2,49.5)
```

The 37 KB subset is committed as
`examples/dhi_pilot/dhi_ndvi_terra_500m_subset.tif`; its SHA-256 and bounds are
in `examples/dhi_pilot/dhi_metadata.json`.

## Pilot commands

```bash
python -m ws4.cli dhi ingest \
  --raster examples/dhi_pilot/dhi_ndvi_terra_500m_subset.tif \
  --blocks examples/dhi_pilot/blocks.geojson \
  --output examples/dhi_pilot/dhi_values.csv \
  --metadata examples/dhi_pilot/dhi_metadata.json \
  --source-version "MODIS 6.1 Terra NDVI Composite RGB (2003-2022)" \
  --retrieved-utc "2026-10-26T00:00:00+00:00"

python -m ws4.cli build \
  --xml examples/dhi_pilot/recipe.xml \
  --fragments examples/dhi_pilot/fragments.csv \
  --out /tmp/dhi-pilot/compiled

python -m ws4.cli simulate \
  --dataset /tmp/dhi-pilot/compiled \
  --schedule examples/dhi_pilot/schedule_baseline.csv \
  --years 10 --out /tmp/dhi-pilot/baseline \
  --dhi-values examples/dhi_pilot/dhi_values.csv \
  --dhi-metadata examples/dhi_pilot/dhi_metadata.json

python -m ws4.cli simulate \
  --dataset /tmp/dhi-pilot/compiled \
  --schedule examples/dhi_pilot/schedule_harvest.csv \
  --years 10 --out /tmp/dhi-pilot/harvest \
  --dhi-values examples/dhi_pilot/dhi_values.csv \
  --dhi-metadata examples/dhi_pilot/dhi_metadata.json

python -m ws4.cli report --run /tmp/dhi-pilot/harvest \
  --targets examples/dhi_pilot/targets.yaml
```

## Results

- Ingest: 4 blocks, bands `cum,min,var`; all values in `[0, 1]`.
- Baseline: `feature.DHI.area` stays at 40.0 ha.
- Harvest (block 1 at offset 0, block 3 at offset 5): final
  `feature.DHI.area` is 20.0 ha; the DHI totals fall by the removed blocks.
- `report_dhi.csv` carries baseline, final, change, percent change, unit,
  source fields, and the caveat.
- `GET /api/runs/{run}/dhi?format=geojson` returns four features with a
  `dhi` property and each band as a property.
- Coverage: the ingest raises `DhiError` when a block has no valid pixel or
  when the source version/coverage fields are dropped.
- Verification: `python -m pytest tests/test_dhi.py -q --no-cov` -> 10 passed;
  `python scripts/dashboard.py` -> GREEN.

## Limits

The four blocks are synthetic 10 ha squares inside a real AOI. The DHI product is
a 2003-2022 composite, not an annual series; the account's trajectory is
schedule-driven. A treated block leaves the account permanently for the run, and
no regrowth, species model, or objective change is implied. Keep the 500 m scale
visible in any interpretation.
