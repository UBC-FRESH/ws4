# TSA24 support map provenance

Date: 2026-11-26
Status: superseded by the canonical area-overlap map

The canonical TSA24 support map is now generated by `scripts/build_support_map.py` using positive
block-cell overlap and cell-share weights. See `notes/reports/support-map-builder.md` and
`notes/reports/support-map-sensitivity.md` for the method, counts, block-area validation, and applied
case comparison.

Canonical SHA-256 in the archive:
`f47b36eb75a80709a0c2a289671487ef9348bfd0720b162dc52d5e1ddb5c41f4`.

The old frozen map (1,111,565 cells; 1,310,129 memberships; median block-area error 64.1%) is retained
as `tsa24-full-250m-support-frozen-legacy.npz` for sensitivity only. This note is kept as a historical
pointer; it is not the current provenance statement.
