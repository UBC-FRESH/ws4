# ssn digitisation status

Source: `ssn` Sitka spruce natural stands, version unversioned, catalogued in
`ws4/sdmd/data/sdmd/source_catalog.json`.

Stored as `cdf-cwh-ss-natural.json`, **provisional**.

## Curve map

- Top height: 6, 8, 12, 16, 20, 24, 28, 36, 44, 52 m, dash `[ 2 2 ]`, width 1.5.
- QMD: 5, 10, 15, 20, 25, 30, 40, 50, 60, 70, 85 cm, dash `[ 6 2 ]`, width 1.5.
- Competition: path 692, dash `[ 2 2 2 2 10 2 ]`, width 2.0.
- Self-thinning: path 691, same dash and width.
- Crown closure: provisional raster trace, 200-4,000 TPH.

The top-height and QMD path assignments are label-driven: each printed label was
matched to the path passing through its x position. The boundary pair is the long
dash-dot pair, with path 692 lower at high TPH.

## Limits

- The crown-closure curve is a raster trace, not a single vector path.
- The diagram is not site-series-specific; it covers the coastal Sitka spruce
  range. Do not claim a BEC-variant fit from this alone.
- Review the figrecover overlay before use.
